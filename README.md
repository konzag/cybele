## 🌐 index.html — Παιχνίδι στο Browser

### Πώς να το τρέξεις

Απλώς **κάνε διπλό κλικ** στο αρχείο `index.html`
ή σύρε το μέσα σε Chrome / Edge / Firefox.

**Δεν χρειάζεται internet!** Λειτουργεί εντελώς offline.

### Τι περιέχει

- **👾 Κυνήγι Δαιμόνων** — Χαριτωμένα δαιμονάκια εμφανίζονται στην οθόνη.
  Πάτα τα να τα πιάσεις! Μετράει πόσα έπιασες.

- **🎨 Χρώματα & Αριθμοί** — Κάθε δαιμονάκι έχει χρώμα και αριθμό (1-5).
  Πριν εξαφανιστεί, λέει το χρώμα και τον αριθμό του στα ελληνικά.

- **🌙 Ημέρα / Νύχτα** — Κουμπί για εναλλαγή. Τη νύχτα τα δαιμονάκια
  λάμπουν και ακολουθεί φακός το δάχτυλό σου!

- **🎉 Γιορτή** — Όταν πιάσεις όλα: κομφετί, αστέρια και μεγάλο μπράβο!

### Συμβατότητα

Λειτουργεί σε κινητό, tablet και υπολογιστή.
Μεγάλα κουμπιά για μικρά δαχτυλάκια! 🤏

### Γνωστοί περιορισμοί / προσβασιμότητα

- **Χωρίς zoom με τα δάχτυλα (εσκεμμένα).** Η σελίδα έχει
  `<meta name="viewport" content="… user-scalable=no">`, ώστε τα μικρά χεράκια να μη μεγεθύνουν
  κατά λάθος τη σελίδα όταν πατάνε γρήγορα τα δαιμονάκια. Αυτό αποκλίνει από το WCAG 1.4.4
  (Resize Text, AA· κανόνας axe `meta-viewport`) και είναι **αποδεκτή εξαίρεση με απόφαση του
  ιδιοκτήτη** (OWNER DECISION 10, 2026-10-22). Το τεστ `tests/ui/axe.spec.ts`
  («axe WCAG 2 A/AA, any impact = 0») δέχεται μόνο αυτόν τον έναν κανόνα στο viewport `<meta>`·
  κάθε άλλη παράβαση A/AA αποτυγχάνει κανονικά. Ο μεγάλος γονέας μπορεί να μεγεθύνει από τις
  ρυθμίσεις του browser (π.χ. Ctrl + / μέγεθος κειμένου).

---

## Τι άλλαξε

- **2026-10-22** — Το `user-scalable=no` μένει (απόφαση ιδιοκτήτη 10) και γράφτηκε ως εξαίρεση
  προσβασιμότητας παραπάνω. Το τεστ WCAG A/AA (κάθε σοβαρότητα) δεν είναι πια «αναμενόμενη
  αποτυχία» (`test.fail`): περνάει, δεχόμενο μόνο το `meta-viewport` στο viewport `<meta>`.
  Καμία αλλαγή στο παιχνίδι (`index.html`, `cybele.py`).

## 🐍 cybele.py — Παιχνίδι στο Terminal

### Απαιτήσεις

- Python 3.7+
- Windows (για τους ήχους με `winsound`)
- `colorama` (προαιρετικό, για χρώματα):

```bash
pip install colorama
```

### Πώς να το τρέξεις

```bash
python cybele.py
```

Ή διπλό κλικ αν έχεις Python συνδεδεμένο με `.py` αρχεία.

### Μενού

| Επιλογή | Παιχνίδι |
|---------|----------|
| `1` | 👾 Κυνήγι Δαιμόνων — Μετράμε δαιμονάκια μαζί (1–5) |
| `2` | 🎨 Χρώματα — Έγχρωμα μπλοκ και ερωτήσεις |
| `3` | 🔢 Αριθμοί — ASCII αριθμοί 1-5 με αστεράκια |
| `4` | 🎵 Τραγουδάκι — Μελωδία με `winsound.Beep()` |
| `5` | 👋 Αποχαιρετισμός — Γεια σου Κυβελίτσα! |
